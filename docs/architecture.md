# Устройство первой версии «НеКрапива»

## Границы

Статическая PWA без учётных записей, сервера записей и облачной синхронизации. HTML, CSS и JavaScript хранятся в кэше приложения; дневники — отдельно в IndexedDB. Файлы оригинальной иконки и авторского блока перенесены из согласованного макета. Установка имеет собственные manifest id/scope, имя базы и префикс кэша, не затрагивает другие приложения семейства.

## Модули

- `app.js`: маршруты, формы, черновики, последовательная очередь сохранения, диалоги, импорт/экспорт и конфликты между вкладками.
- `views.js`, `ui.js`, `style.css`: доступные элементы интерфейса, единый авторский блок, справочная информация и печатный отчёт.
- `model.js`: структура данных, проверка ссылок, версии назначений, периоды, наблюдения за факторами, удаление пациента, подготовка и объединение резервных копий.
- `storage.js`: атомарная транзакция метаданных и фотографий, проверка ревизии, чтение изображений.
- `definitions.js`: рабочие русские тексты доступных форм.
- `registry.js`, `age-policy.js`: возраст, показания, назначение инструментов, ограничения, язык/версия/источники, снимок контекста оценки.
- `scoring.js`: чистые функции расчёта, пропуски и проверки полноты периодов.
- `runtime.js`, `sw.js`, `manifest.webmanifest`: установка, обновление по действию пользователя, изолированный кэш оболочки.

## Данные

`patients`, `days`, `plans`, `intakes`, `edema`, `factors`, `assessments`, `photos`, `emergency`, `questions`, `drafts`. Каждая запись принадлежит одному пациенту. Blob фотографий хранится отдельно от метаданных, но сохраняется/удаляется в той же транзакции.

Профиль не предполагает диагноз при незаполненных полях. Сохранённая оценка содержит возраст на дату, период, версию, способ ответа и исходные ответы. Последующее изменение профиля не пересчитывает историю. Формальные показатели не вычисляются при неизвестном возрасте или неподходящей ситуации. Для дневника младшего ребёнка доступны описательные записи.

UAS7 требует 7 последовательных полных суток. AAS7/AAS28 — соответственно 7/28 суток. Смешение версий, ответчиков или часовых поясов не даёт полного индекса. UCT, AECT и AE-QoL имеют отдельные результаты; суммарный «общий индекс» не создаётся.

Назначение изменяется новой версией с датой действия. Фактический приём содержит ссылку и снимок выбранной версии, фактическое количество вводится отдельно. Отмеченные обстоятельства считаются самостоятельными событиями. Редактирование одного события не увеличивает счётчик.

## Сохранение и восстановление

Приложение показывает успешное сохранение только после `transaction.oncomplete`. Ошибки квоты, блокировки или чтения не вызывают сброса базы. При изменениях из другой вкладки проверка ревизии предотвращает молчаливую перезапись; введённый текст остаётся на экране. Дополнительно сравнивается версия редактируемой записи.

Импорт сначала проверяет формат, таблицы, даты, ссылки на пациента и декодирование изображений. Затем показывает состав. Добавление создаёт новые идентификаторы, включая вложенные снимки пациента и назначения. Замена совпадающих дневников требует отдельного действия. Любая ошибка прерывает общую транзакцию, не оставляя частичного импорта.

JSON — переносимый резервный файл, фотографии включены по умолчанию. PDF — сводка плюс все записи периода; фотографии выключены по умолчанию и выбираются отдельно. HTML/TXT/ICS не добавлены.

## Выпуск

Готовые файлы обновляются `tools/build.py` и сохраняются в Git. GitHub Pages публикует корень ветки `main` в режиме Deploy from a branch, как другие приложения семейства. `.nojekyll` предотвращает преобразование файлов. `dist/` остаётся дополнительным пакетом для переноса. Собственный workflow только проверяет код; публикацию выполняет системный процесс GitHub Pages.

Каждая сборка имеет хеш содержимого. Новый service worker ожидает нажатия кнопки и не предлагает закрыть несохранённую форму. Старый кэш удаляется только внутри собственного префикса. Никакие обновления оболочки не очищают IndexedDB.

Физические устройства и публичный HTTPS-адрес проверяются после публикации. Напоминания в этой версии отображаются при открытии приложения; гарантированные уведомления при закрытой PWA не заявляются.
